# notes angular and flask

a simple notes app without login page

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Angular 22 app (Vite, Analog). Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a Flask service. No architecture had been approved when this
  repository was created, so it starts with its health check and nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
flask --app app run --debug
pytest
ruff check .
ruff format .
```
